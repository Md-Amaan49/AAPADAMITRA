# AAPADAMITRA — Web Application

React + TypeScript frontend application scaffolded with Vite for AAPADAMITRA.

## Development Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript (strict mode)
- **Linter:** ESLint

## Environment Variables
- `VITE_API_BASE_URL`: Base URL for API endpoints (e.g. `http://localhost:3000/api/v1`)
- `VITE_APP_TITLE`: Application title

## Commands

```powershell
# Run development server (http://localhost:5173)
pnpm --filter @aapadamitra/web dev

# Production build
pnpm --filter @aapadamitra/web build

# Linting
pnpm --filter @aapadamitra/web lint
```
